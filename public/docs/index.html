API v1

Konten dari satu workspace, untuk setiap aplikasi Anda. Gunakan REST API untuk mengambil artikel, halaman, media, dan struktur situs.

Format JSONBase URL /api/v1Autentikasi API key per situs

Request pertama

Ambil API key situs dari workspace. Ganti YOUR_SITE_API_KEY dengan key Anda, lalu jalankan contoh ini di terminal.

Atau coba langsung di bawah ↗
TerminalcURL
curl 'http://localhost:3000/api/v1/posts?perPage=5' \
  -H 'x-api-key: YOUR_SITE_API_KEY'

Gunakan domain server CMS Anda saat integrasi.

Satu key untuk setiap situs.

Kirim API key melalui header x-api-key. Di referensi berikut, klik Authorize dan masukkan key situs sebelum menjalankan request. Key hanya memberi akses ke konten situs terkait.
