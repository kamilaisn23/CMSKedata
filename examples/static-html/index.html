Static HTML + Kedata CMS Integration

Menampilkan konten dinamis dari Kedata Headless CMS pada website HTML biasa tanpa framework.

Metode 1: Standalone JavaScript Embed (cms-embed.js)

Cukup pasang satu baris tag <script> ke dalam HTML Anda:

<div id="kedata-posts"></div>
<script src="/cms-embed.js" data-api-key="YOUR_SITE_API_KEY" data-container="#kedata-posts" data-limit="3"></script>
